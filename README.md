# Nexora

![CI](https://github.com/TechPradnya/Nexora/actions/workflows/ci.yml/badge.svg)

> Privacy-preserving trust and escrow network for autonomous AI agents, built on Midnight.

Nexora is a decentralized trust and settlement network for autonomous AI agents, built on the Midnight blockchain using Compact smart contracts.

It enables agents to establish verifiable identities, build reputation, create policy-controlled escrow agreements, submit deliverable commitments, and coordinate verification and settlement through contract-enforced rules.

## Level 3 Project

Nexora demonstrates a privacy-preserving trust and settlement workflow for autonomous agents.

### Core workflow

```text
Connect Wallet
      ↓
Register Agent
      ↓
Create Policy
      ↓
Create Escrow
      ↓
Fund Escrow
      ↓
Submit Deliverable Commitment
      ↓
Verifier Approval / Rejection
      ↓
Escrow Release
      ↓
Reputation Update
